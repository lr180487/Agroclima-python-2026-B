🔌 API pública de AgroClima

Integra el motor analítico agroclimático en tus propios sistemas: apps móviles, ERPs agrícolas, bots o tableros externos. Documentación completa también en /docs (Swagger).

🔑 Mis API keys

Para integraciones externas sin JWT: envía la clave en el header X-API-Key. Máx. 10 claves.

Aún no tienes claves. Genera la primera.

📚 Endpoints principales

POST/api/v1/analyze

Motor analítico completo: índice 0–100, estado, alertas y recomendaciones.

# Body JSON: { "lat": -13.31, "lon": -72.12, "crop": "maiz" }

GET/api/v1/analyze?lat=&lon=&crop=

Variante GET del análisis, ideal para curl o pruebas rápidas.

GET/api/v1/crops

Catálogo público de cultivos y rangos agroclimáticos (sin autenticación).

GET/api/parcels · /api/history

Tus datos (JWT). Ver todos los endpoints en /docs.

💻 Ejemplo de integración

# Con API key (integraciones externas): curl -X POST https://tu-dominio/api/v1/analyze \ -H "Content-Type: application/json" \ -H "X-API-Key: agk_tu_clave_aqui" \ -d '{"lat":-13.31,"lon":-72.12,"crop":"maiz"}' # El mismo motor vía backend Google Apps Script: curl -X POST https://script.google.com/macros/s/…/exec \ -H "Content-Type: text/plain" \ -d '{"action":"weather/analyze","payload":{"lat":-13.31,"lon":-72.12,"crop":"maiz"}}'
