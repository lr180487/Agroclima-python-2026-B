🔌 Stack de integraciones

APIs que impulsan AgroClima

Seis servicios externos conectados en tiempo real. Cinco de ellos son gratuitos y de datos abiertos — sin API keys.

🌦️
GRATIS SIN API KEY

Open-Meteo

api.open-meteo.com/v1/forecast

Fuente meteorológica principal. Combina modelos numéricos globales y regionales (ECMWF, GFS, ICON) con resolución de hasta 1 km.

  • ✅ Clima actual: temperatura, sensación, humedad, viento, precipitación
  • ✅ Pronóstico diario 7 días + histórico hasta 30 días (past_days)
  • ✅ Radiación solar (W/m²), punto de rocío, índice UV, códigos WMO
  • ✅ Consulta multi-ubicación en una sola llamada (temperaturas de todas las parcelas)

Usada en: Dashboard, Analizador, Mapa, Notificaciones

📍
GRATIS OPEN DATA

Nominatim (OpenStreetMap)

nominatim.openstreetmap.org/search

Geocodificador oficial de OpenStreetMap: convierte nombres de lugares en coordenadas usando la base de datos colaborativa más grande del mundo.

  • ✅ Autocompletado en vivo mientras escribes (debounce 350 ms)
  • ✅ Búsqueda restringida al Perú 🇵🇪 con countrycodes=pe + viewbox
  • ✅ Encuentra distritos, valles, caseríos, ríos y calles
  • ✅ Detalle de dirección: departamento, provincia, tipo de lugar

Usada en: Buscador del Dashboard y del Mapa

🗺️
GRATIS OPEN SOURCE

Leaflet + Tiles OSM

tile.openstreetmap.org/{z}/{x}/{y}.png

Librería JavaScript líder para mapas interactivos (42 KB) renderizando los mosaicos cartográficos de OpenStreetMap y OpenTopoMap.

  • ✅ Mapa interactivo con zoom 19 y marcadores personalizados por cultivo
  • ✅ Capa topográfica (OpenTopoMap) para relieve andino
  • ✅ Popups, vuelos animados (flyTo) y control de capas
  • ✅ Etiquetas de temperatura en vivo sobre cada parcela

Usada en: Mapa de parcelas

🌧️
GRATIS EN VIVO

RainViewer

api.rainviewer.com/public/weather-maps.json

Red mundial de radares meteorológicos agregados: muestra dónde está lloviendo realmente en este momento, no una predicción.

  • ✅ Capa de radar superpuesta al mapa, actualizada cada ~10 minutos
  • ✅ Escala de intensidad: llovizna → lluvia moderada → tormenta intensa
  • ✅ Auto-refresco cada 5 min sin recargar la página
  • ✅ Cobertura global con mosaicos PNG de 256px

Usada en: Mapa (capa "Radar de lluvia")

🛰️
GRATIS SATÉLITE

Esri World Imagery

server.arcgisonline.com/.../World_Imagery

Imágenes satelitales de alta resolución (Maxar, Earthstar Geographics) para inspeccionar visualmente el estado real de los campos.

  • ✅ Vista satélite alternativa al mapa base OSM
  • ✅ Resolución suficiente para distinguir parcelas y surcos
  • ✅ Ideal para delimitar linderos y verificar cobertura vegetal

Usada en: Mapa (capa "Satélite")

OAUTH 2.0 GOOGLE CLOUD

Gmail API

gmail.googleapis.com/gmail/v1/users/me/messages/send

Envío de alertas por correo desde tu propia cuenta de Gmail, autorizado con Google Identity Services y el permiso mínimo gmail.send.

  • ✅ Correos HTML con métricas y alertas del motor analítico
  • ✅ Mensajes MIME RFC 2822 codificados en base64url
  • ✅ Alertas de helada, calor, tormentas, viento y UV configurables
  • ✅ Modo demo sin credenciales para probar sin Google Cloud

Usada en: Notificaciones
